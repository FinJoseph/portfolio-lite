## Fampidirana

**Horloge Mada** dia famantaranandro manan-tsaina natao ho an'ny mpandraharaha call center, mampiseho ny **ora ofisialy eto Madagasikara** (Indian/Antananarivo) amin'ny fotoana tena izy. Manamarika ny fivoaran'ny andro fiasana izy ary mampifantoka ny fampahalalana ilaina rehetra.

## Endri-javatra

- 🕒 Ora ofisialy eto Madagasikara amin'ny fotoana tena izy, **fiteny 5** (FR/MG/EN/HI/ZH)
- 📈 **Fivoaran'ny andro fiasana** (07:00 → 19:00) miaraka amin'ny bara mihetsiketsika
- 🍽️ **Fiatoana sakafo** amin'ny 12:00 (1ora) miaraka amin'ny fanisana miverina
- 💰 **Fanisana andro aloa** (isaky ny 15)
- 🌅 **Lanjatry ny lanitra dinamika** : maraina, andro, hariva, alina — masoandro sy volana 3D
- 🐱 **Saka 3D** mandehandeha tsy ampoizina eny amin'ny pejy miaraka amin'ny hafatra fampaherezana
- 💬 **Chat mivantana** misy emoji, sticker ary GIF mihetsiketsika (Google Noto, tsy misy API key)
- 🔔 **Fanairana feo** (fanombohana, fiatoana, famerenana, fiafaran'ny andro)
- ✨ **Effets 3D** : fihetsika kard rehefa misy cursor, fanjelatra, écran de chargement

## Stack Teknika

| Teknolojia | Fampiasana |
|-------------|-------------|
| Laravel 12 | Framework backend |
| PHP 8.4 | Fiteny serveur |
| Livewire 4 | Composants SFC side-server |
| Alpine.js | Interactivité côté client |
| Tailwind CSS 4 | Styles |
| FrankenPHP | Serveur PHP + Caddy |
| Docker | Conteneurisation |
| Vite 8 | Bundler frontend |
