## Overview

**Professional Portfolio** is a complete portfolio CMS built with Laravel, Filament and Inertia.js. It allows managing all portfolio content through a powerful administration interface.

## Features

### Administration (Filament)
- **10 managed models**: Projects, Articles, Skills, Experiences, Testimonials, Messages, Categories, Tags, Users, Settings
- **Media management** via Spatie MediaLibrary
- **Dashboard** with statistics
- **Database notifications**
- **Custom pages**: Profile, Site Settings

### Public Site (Inertia.js SPA)
- **Multilingual**: French, English, Malagasy (`fr`/`en`/`mg`)
- **Pages**: Home, Skills (detail), Projects (list + detail), Blog (list + detail), Testimonials, Contact
- **Contact form** with rate limiting
- **SEO**: JSON-LD structured data, meta tags, sitemap.xml
- **Dark/Light mode**
- **Responsive navigation**

### Technical
- **SPA architecture** with Inertia.js (no REST API)
- **20 migrations** and **9 seeders**
- **Localized routes** (`fr|en|mg`)
- **Translatable models** via Spatie Translatable
